# Taskdesk implementation notes

This submission implements the required core only; invoices and branch/multi-firm support are intentionally excluded. Sessions use opaque random bearer tokens stored as SHA-256 hashes, expire after 12 hours, and are revoked at logout. Passwords use Argon2id. Email addresses are trimmed/lowercased and globally unique. Employees see clients with at least one task assigned to them. New tasks default to the acting admin when no assignee is provided. Login attempts are limited to 8 per IP per 15 minutes. Passwords are required to be at least eight characters because the brief does not specify a minimum. Due dates and task creation times use epoch milliseconds; fees are stored as NUMERIC(12,2).

The web app is a same-origin Next.js backend-for-frontend that stores the API token in an HttpOnly cookie; browser code never calls the API origin. Date-only form values are interpreted at local midnight before conversion to epoch milliseconds. `.env.example` uses local placeholders and must be updated for the actual PostgreSQL host, database, and accounts. There is no seed data. Tests use a real PostgreSQL database and create/clean up their own firm fixtures. Role checks and firm scoping are enforced by the API even when the interface hides actions.
